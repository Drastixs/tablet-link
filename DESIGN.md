# Interface

## Scene

The owner opens the tablet beside their Linux desktop, in a well-lit room, and expects the desktop image to appear without navigating settings.

## Approach

Use a quiet light setup screen with a single deep-green action and plain status text. Once connected, the screen image takes the full tablet surface. A small Disconnect action stays visible at the top right. Errors return to setup with the reason in red.

## Colors

- Canvas: warm off-white, `#f6f7f5`
- Text: blue-tinted charcoal, `#1e252b`
- Accent: deep green, `#235b4d`
- Error: muted red, `#9c3730`

Android system typography and native controls keep the setup legible and familiar.
